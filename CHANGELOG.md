# Changelog

## 0.1.0 (unreleased)

- Added: five sources, each sampled from the running service on 2026-11-08: the hosted gateway's OpenSearch events (seven kinds of JSON document, field names measured), the Prompt-Guard sidecar's verdict lines, the banking MCP server (header line plus indented context lines carrying the trace id), the LLM proxy's routing lines, and the authz server (each decision printed twice, readable and JSON). Real PingFederate (server log on stdout, half DEBUG) and Ping Gateway (a repeating router ERROR) lines added to the two existing products. Not added: weather, Brave, audit, HITL, agent-service (start-up lines only).
- Added: Alloy ships the five local services in Real mode (exact container names), with a rate limit on the whole pipeline; the compose test pins the names and the limit stage.
- Added: a seventh source, the Privilege hosted gateway (`agentless-mcpgw`), with six line shapes measured on 2026-11-08: who is calling, which app, forwarded to the backend (the only sign of an allowed call), refused by policy (level info), policy-evaluation noise, and a guardrail block. Ids and hostnames are placeholders.
- Added: click a log line to open it. The detail shows the exact time, labels, the whole message, the fields found in it (JSON or key=value), what kind of line it is with its honesty label, and a trace button. Closed rows look as before. Keyboard: Enter or Space. Selecting text in a line does not collapse it.
- Added: Privilege agent gateway (`ping-mcpgw`) as a sixth source (lab PR #1).
- Changed: the agent gateway mock writes the two rejection messages as a pair from one request (measured: 22,022 of 22,192 invalid-token lines directly follow a missing-header line), not as two independent streams. Added: the four `[SERVER]` request lines (Incoming request, User-Agent, Remote Addr, Content-Type) to the mock and to the Alloy filter; a refused request to an MCP app path writes no line (measured).
- Added: Privilege logs in the own stack: node sensor and MCP gateway from stdout, agent gateway from AI-DEMO2's log volume (optional `docker-compose.privilege.yml`, read-only, tail from end, three message families kept). Alloy drops container history older than 15 minutes (a restart otherwise made Loki reject the replay).
- Added: own log stack (compose profile `stack`: Loki 3.3.2 + Alloy v1.19.2 sharing the lab's network namespace, nothing extra published) and a Playwright browser driver in Docker (profile `drive`) that visits labs through the lab-proxy so Alloy ships real access-log lines. See README.

- Core: seeded mock log stream for PingOne, PingFederate and Ping Gateway (replayed relative to now), LogQL-lite with literal-only regex operators, three alert rules (burst, ratio with a traffic floor, silence), per-workspace incidents and relabel switch, runtime Mock/Real toggle, read-only loopback Loki client for Real, W3C traceparent on every hop, doctor that replays every scenario.
- Web: Logs, Products, Pipeline (diagram-studio/1 data), Label lab, Alerts, Talk track; presenter mode.
- Port 7800 (one port, from the shelf allocator; the first draft used 7720-7729, which meridian-a2a-hop already owns). Catalog id D123 (chosen by the owner 2026-11-07; D122 belongs to a2a-lab).
