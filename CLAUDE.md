# observability-lab

Demo-tier standalone app: follow a log line from PingOne, PingFederate and Ping Gateway to a searchable, alertable store; the label lab shows the silent failure when the collector's relabel rule is missing. Derived from the AI-DEMO2 monitoring stack (read-only source, never imported).

- Run: `./scripts/run.sh` (http://localhost:7800). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track`. Content pack: `npm run content-pack`.
- Core: `server/src/logStore.js` (seeded stream replayed relative to now, incidents, `serviceLabel` = the relabel switch), `logql.js` (LogQL-lite, ReDoS-safe: regex operators take only a literal alternation), `alerts.js` (3 rules: burst, ratio with traffic floor, silence), `lokiClient.js` (Real: read-only GET query_range to ONE loopback Loki, no redirects, body cap, query rebuilt from the parsed form), `config.js` (`OBS_LOKI_URL` must be loopback), `logData.js` (story, products, scenarios, facts with measured/inferred/UNVERIFIED status, `{{cast}}` tokens, 3 vertical packs), `trace.js` (W3C traceparent per hop), `doctor.js` (also replays every scenario against the engine).
- Rules that bite: loopback bind only; same-origin writes; zero outbound network (netguard) — that is WHY Real only accepts a loopback Loki; only `.example`/`.invalid` hosts; one port, 7800; `POST /api/mode` is exactly `{ source: "mock"|"real" }` and switches at runtime (409 + reason when Real is unavailable); incidents/relabel are mock-only (409 in Real); mock events are replayed relative to now so nothing ages out.
- Honesty rule: every product claim has a status. Line shapes are UNVERIFIED (illustrative). `measured` facts must stay within what the cited AI-DEMO2 file comment says (named in the text). Do not upgrade one without reading the source again.
- Alert semantics (do not weaken): the gateway rule needs a traffic floor (>= 10 requests / 5 min) AND >= 50% 5xx and never counts 401; the burst rule counts FAILURE lines in 5 min (>= 5); the silence rule fires when a service has no lines in 10 min.
- Web: `web/src/App.jsx` (seven tabs, presenter, Reset, runtime Mock/Real toggle that reloads all data via `dataSignal`), `components/` LogStream, Products, LabelLab, Alerts, Searches, Hops, DiagramTab + PatternDiagram (scaffold). Colours from `tokens.css` only. Log lines render as React text through `visible()`; never `dangerouslySetInnerHTML`.
- Attribution: scaffold copied from delegation-lab-LAB; see README. No cross-repo imports.
- Searches tab: the catalog and the Discover-link helper (`rison`, `discoverUrl`, `kqlString`) live in `server/src/searches.js`, pure and shared by config.js and the web app (the Dockerfile copies it into the web build). A typed value goes into KQL only through `kqlString` (escapes `\` and `"`, refuses empty). Every search was measured against the real index before shipping; re-measure before adding one.
- Docker + SIEM: profile `siem` adds `siem-forwarder` (socat in the lab namespace, 127.0.0.1:9200 -> host.docker.internal:9200). The lab's own SIEM URL check stays loopback only; do not widen it.
